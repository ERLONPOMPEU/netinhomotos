# Netinho Motos — versão para GitHub Pages

Esta pasta já contém o site completo em HTML, CSS e JavaScript puro. Não precisa instalar programas nem executar comandos.

## Arquivos

- `index.html`: estrutura e textos do site
- `style.css`: cores, layout, responsividade e efeitos visuais
- `script.js`: menu, animações, cards e links do WhatsApp
- `images/`: as quatro imagens usadas no site

## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub.
2. Envie **todo o conteúdo desta pasta**, mantendo a pasta `images`.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main`, a pasta `/ (root)` e clique em **Save**.

Depois de alguns minutos, o GitHub mostrará o endereço público do site.

Importante: não altere os nomes das imagens nem mova os arquivos para outras pastas, pois os caminhos já estão configurados.
